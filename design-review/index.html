Needs a decision

  • Funding logos (Creative Europe MEDIA, Fédération Wallonie-Bruxelles, VAF) and the Amazon SSO mark are still PNGs: no vector source exists in Brilliant or simple-icons. Supply SVGs or approve keeping the rasters.
  • Footer copyright is white/40 on black (3.65:1), below WCAG AA 4.5:1. Kept as designed; raise to text.muted (white/60) or accept.
  • LoginModal.SelectedProduct is 352px wide; 'MONATSABO – 7,99 €/Monat' plus the pill doesn't fit (the master overlaps the pill onto the price, code wraps the line). Widen the slot, shorten the copy, or drop the pill at this size.
  • LanguageSelect has no open/menu state in the design; the dropdown in code is an implementation choice.
  • Social Icons 'Original': Instagram and Spotify render on a white tile in the master, YouTube and Facebook do not. Code renders all four without a tile.
  • Responsive strategy: one responsive component per concept in code (container queries); Brilliant keeps breakpoint variants only where the structure changes (Header, Footer viewport axis). Header/Footer no longer take a viewport prop.
  • PlanCard stories use a placeholder still (The Seventh Seal, public/images/placeholder/seventh-seal.webp) for the image slot. Story-only; design screens keep their own artwork.
  • Component library copy is generic (2026-10-21): masters and stories use placeholder copy (Film Title, Director Name, Headline, Section Title, Lorem ipsum for eyebrows and body, 'Button' on generic buttons). Contextual actions keep English labels (Subscribe, Rent, Trailer, Watch Now, Add to list). Contextual components keep production copy: PlanCard, ProductCard, UniOffer, LoginModal, Header, Footer, AvailabilityFilter. Design screens keep their real content through instance overrides; story fixtures live in src/mocks/placeholder.ts, screen data in catalog.ts / editorial.ts.
  • Search segmented sketches (Films/Series, Genres/Themes/Filters, Subscription/Rentals with the Sooner icon) are on no screen, so they stay sketches on 2 Components › Search. Results title follows production 'Ergebnisse für „…“' on the German screen; the design reads 'Search Results: Drama'.

Design gaps (fixed in code, flagged for the design)

  • Synced 2026-10-20 (production = truth): Button master and code follow .sooner-cta-* — primary 600/uppercase/0.03em, white 600 with white/85 hover and 60% disabled, ghost 500 with blur 10, lg 16/32 padding. The generated focus variants were removed from the master, board and code; keyboard focus is production's 2px white outline (offset 2).
  • Synced 2026-10-20: LoginModal and PlanCard masters now compose Button instances instead of hand-built button frames; the generated 'Sooner / Component library' duplicates and the detached Signup production frames moved to canvas '8 _archive'.
  • TextInput error is a white border in the master; code uses status.error (red-500) for border and message (your call).
  • TextInput default border: email is full white, password white/30 in the master; code uses white/30 for both (your call).
  • TextInput: the password type only has a 'default' variant on the master; other password states reuse the email styling.
  • LoginModal 'focus' omits the SSO block and Hochschul-Login in the master; code keeps them (only 'disabled' drops them).
  • PlanCard: the yearly master overrides the title to 32px; code keeps heading.plan (30px).
  • PlanCard film stills are placeholders and were removed; the 384×199 image slot takes an optional imageSrc.
  • Unbound values in masters: ProductCard shadow (0 4 8 / 25%), yearly PlanCard CTA shadow (0 3 8 / 25%), cta-white hover shadow (0 4 8 / 10%), TextInput supporting text #9CA3AF (Tailwind v3 gray-400; code uses v4 gray-400 #99A1AF), Button ghost blur 5 (DS says CTAs blur 10).
  • Copy inconsistency: the cta-light Button master says 'UNI wählen', the UniOffer master 'UNI WÄHLEN'. Code renders each as written.
  • Hover states on NavLink, LanguageSelect, footer links and SSO buttons are not drawn in the design; kept subtle in code (your call).
  • Icons: UI glyphs are Lucide (Search, Menu, ChevronDown, Eye, X, Check, Play); the design's custom chevron (16×8) and pupil-less eye differ slightly.
